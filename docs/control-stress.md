# 饱和动态专项与振荡判据

本专项补充原有 C 饱和单元测试，必须运行真实 UR5/PyBullet DIRECT 动力学。
`--plant second_order` 只用于本地验证脚本，不能作为物理试验记录。

## 配对动态试验

基础配置为 `pid-feedforward.v1.json`，专项配置为 `control-stress.v1.json`。
每次 24 s，dt=0.01 s，每周期 4 个物理子步，0／0.75 kg 两种负载，每种组合重复两次。
PID 与 PID+FF 使用相同参考、初态、负载、PID 参数、扰动和限幅。两组总执行器限幅
统一设为 ±1.2 N·m，积分项仍为 ±3 N·m。该限幅为本专项固定设置，不替换原正常试验的 ±12 N·m。

| 工况 | 参考及扰动 | 参数用途 |
|---|---|---|
| 正向饱和 | 0.5 s 开始，0.25 s 五次曲线从 0 到 +0.3 rad 后保持 | 正常 PID 参数 |
| 反向饱和 | 同上，目标 −0.3 rad | 正常 PID 参数 |
| 过载脉冲 | 0→0.2 rad；2≤t<2.5 s 加 +2 N·m 外力矩 | 正常 PID 参数 |
| 降阻尼诊断反例 | 同正向参考，两组均 Kp=80、Ki=Kd=0 | 故意配置的振荡反例，单列，不推荐使用 |

共 32 次新增动力学试验，76,800 条周期数据。扰动通过 `applyExternalTorque` 独立施加
在 J1 子连杆的世界 z 轴；执行器接口在每个子步只收到已限幅命令。CSV 同时保存请求总力矩、
限幅输出、实际发给每个物理子步的执行器命令最小／最大值、外扰、积分、反馈与两项前馈、
参考及实际角度、误差和限幅标志。这里的“实际限幅”指发给仿真引擎的执行器命令，不是实体力矩传感器测量。

对每段连续饱和保存起止、持续时间、请求力矩范围、起止及释放时积分和释放时误差。
最终释放时刻是最后一次请求超限后的首个未限幅采样点。恢复时间从该时刻计起，直到跟踪误差
始终处于 ±0.004 rad 且尾段至少保持 0.5 s；未恢复或未释放均填 null 并单列。
图像将误差、限幅前请求、物理子步执行器命令、积分分别作图，避免大请求量掩盖实际限幅。

检查请求超限确实发生且至少有一段持续 ≥0.1 s；实际执行器命令、积分均不越限；积分不能
继续朝已饱和方向累积。正常参数组还要求释放后在观察窗内恢复。诊断反例的振荡／未恢复
结果作为预期反例保留，不以修改阈值或删除记录消除。

## 振荡的操作性判据

仅检查参考已恒定的阶段，直接检查跟踪误差绕 0 的正负变化，不对信号去均值或隐藏偏置：

1. 取连续、**不重叠的 4 s 完整窗口**。原正常工况从原报告的终点／扰动时刻开始，新专项从五次参考终点开始。
2. 设置 **±0.0025 rad 滞回阈值**。超过正／负阈值才改变符号，死区内噪声不构成穿越。
3. 收集相邻正负波瓣的极值；**每个半周期的峰峰值至少 0.01 rad** 才计数。
   连续两个合格半周期计一个完整周期，每窗至少 **2 个完整周期**。
4. **连续 2 个窗口** 均满足，才触发；即至少覆盖 8 s。保存首次触发时刻、每窗峰峰值、
   极值序列、合格周期数及连续窗口数。
5. 只有一个合格窗口、单次超调、缓慢漂移、小幅噪声均不触发。没有完整窗口则明确标记
   `insufficient_window`，不能写成“未触发”。

这是一项有限观察窗内的阈值振荡诊断，不等同于数学意义上的失稳证明。
合格半周期要求防止“一次大尖峰加多次小噪声穿越”误判为持续振荡。

原有 40 次正常物理对照和新增 32 次物理试验均逐项判断。结果不默认为通过：

- `oscillation-cases.csv`：逐项列出 detected／not_detected／insufficient_window，触发与未触发都保留。
- `saturation-cases.csv`：逐项列出请求超限、实际限幅、实际越限数、积分和最终释放／恢复时间。
- `exception-cases.csv`：单列请求饱和、振荡、实际越限和观察窗内未恢复，注明是否诊断反例。
- `report.json`：保留所有窗口、饱和区间、配对参数、重复性及逐例 CSV 哈希。
- 每个试验的原始 CSV 和两组恢复对照 SVG 均随 CI artifact 保存。

## 复现

先运行原有物理对照以产生待复核的正常案例，再运行本专项：

```bash
python scripts/verify_pid_feedforward.py --library build/librobot_control.so --plant pybullet --output results/pid-feedforward-pybullet
python scripts/verify_control_stress.py --library build/librobot_control.so --output results/control-stress-pybullet
```

`test_control_diagnostics.py` 只验证判据的正负合成信号及区间统计；物理饱和与释放证据由第二个命令产生，二者不互相替代。
