## TCP 限值

| 量 | 单位 | 基础值 | 默认实际使用上限 | 来源 / 适用范围 / 版本 |
|---|---|---:|---:|---|
| TCP线速度模长 | m/s | 0.25 | 0.125 | S3；仿真；v1.0.0 |
| TCP角速度模长 | rad/s | 0.5 | 0.25 | S3；仿真；v1.0.0 |
| TCP线加速度模长 | m/s² | 0.5 | 0.25 | S3；仿真；v1.0.0 |
| TCP角加速度模长 | rad/s² | 1.0 | 0.5 | S3；仿真；v1.0.0 |

S3：执行者于2026-10-10选定的低速仿真实验上限，**不是厂家TCP额定能力**。参数修改需新修订号、配置哈希和对应回归；本表由版本配置约束。

TCP 明确为 **URDF `tool0` 坐标系原点**，不是 flange 原点、工具外壳点或负载重心；`T_tool0_tcp=I`。工程 FK 输出 base→tool0，所有线速度/加速度及空间角速度/角加速度向量在 **base 系**表达，输入形状均(3,)；角速度不是欧拉角导数。更换工具偏置或TCP需要独立修订并重新核对，不能只替换名称。

四项均按欧氏模长 `sqrt(x²+y²+z²)` 判断，不逐分量判断。例如默认线速度上限0.125 m/s下，[0.1,0.1,0]各分量均低于0.125，但模长0.141421超过上限，必须拒绝。关节速度/加速度则逐轴检查绝对值。等于上限可接受；超过上限返回3002，不自动裁剪。单个节点检查不证明连续轨迹各时刻都满足约束，后续规划还必须验证连续段极值。

## 缩放与调用规则

实际使用上限 = **基础值 × 配置缩放 × 请求缩放**。配置速度/加速度缩放分别为0.5/0.5；请求默认1/1，只允许(0,1]，不得超过配置上限。关节速度、TCP线/角速度共用速度缩放；关节加速度、TCP线/角加速度共用加速度缩放。请求二次缩放不改变文件或原模型，返回对象和报告保存总缩放、实际数值及配置/模型SHA-256。

```python
from planning.limits import load_planning_limits
limits = load_planning_limits()  # 唯一默认文件；失败不得启动规划
limits.check_joint_rates(qd_rad_s, qdd_rad_s2)
limits.check_tcp_rates(v_base_m_s, omega_base_rad_s,
                       a_base_m_s2, alpha_base_rad_s2)
```

配置绑定模型字节SHA-256；模型发生任何修改需重新审查并更新绑定。本版本拒绝非仿真用途(1008)。文件/必需字段不存在或为null返回1004；NaN/Inf、零/负限值、错误形状/缩放返回1001；单位1002、轴序1003、TCP/坐标/模长规则1007。`load_planning_limits`抛统一 `ContractError`，上层将非0码映射成 `data=null`，不得产生部分正式轨迹。没有有效 `PlanningLimits` 时，正式规划入口必须拒绝；静止关节plan_joint子集已实现；plan_cartesian仍待实现。
